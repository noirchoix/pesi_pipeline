# Data Card — Herbicide Target Atlas

## File
`data/reference/herbicide_target_reference.csv`

## Purpose
Encodes literature-grounded herbicide target families, sites of action, known inhibitor classes, selectivity mechanisms, and resistance risks.

## Included target families
ACCase, ALS/AHAS, EPSPS, glutamine synthetase, PPO, PSII, PSI, tubulin/microtubule, VLCFA, CAZy/cell wall, cytochrome P450 detoxification, oxidative stress enzymes.

## Use
The atlas maps candidate critical enzymes to herbicide-biology target rules and improves Aim 4 scoring.

## Limitations
Rule-based target mapping is conservative and must be expanded with curated target/inhibitor evidence and assays.
