# PESI Report Interpretation and Aggregation Upgrade

## Purpose

This upgrade replaces row-by-row report repetition with a grouped, evidence-grounded scientific interpretation layer. The primary report is written for a researcher; internal scores, tokens, artifact filenames, and model fields are retained in a separate technical appendix.

## Implemented behavior

1. Recommendations are grouped by unordered unique compound pair.
2. Each pair lists all retained target-enzyme contexts rather than repeating the pair as separate report entries.
3. FoodDB output includes actual food or ingredient names for each mapped compound and any shared pair source.
4. Compound-level FoodDB match status, match method, confidence, and source count are reported.
5. Internal stage, evidence, source, and class tokens are translated into readable scientific language.
6. Named provenance identifies curated target evidence, FoodDB occurrence evidence, enzyme-state artifacts, selectivity artifacts, pairing artifacts, and other generated evidence files.
7. Scenario-selectivity signals are interpreted as comparative crop-versus-weed screening proxies.
8. Pseudo-lab output is translated into per-target and per-pair relative assay-priority bands. These are not doses or field rates.
9. The report states whether the executive synthesis was generated by DeepSeek or by the deterministic artifact-grounded fallback.
10. Raw scores, internal model fields, evidence paths, and artifact filenames are isolated in a collapsible technical appendix in HTML and a structured `technical_appendix` object in JSON.

## JSON report additions

- `interpretation_mode`
- `executive_summary`
- `pair_groups`
- `technical_appendix`
- grouped `recommendations`
- named evidence provenance
- compound-level FoodDB match details
- target-specific assay-priority bands

## Scientific boundary

The report explains computational screening priority. It does not establish pesticide efficacy, extractability, formulation suitability, crop safety, environmental safety, dose, field rate, or regulatory readiness.
